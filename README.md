# 數位校園大逃脫：消失的教學金鑰

高雄市楠梓區油廠國民小學 iPad 基礎操作研習用的密室逃脫網頁遊戲。純靜態網站，可直接部署到 GitHub Pages，不需要伺服器、帳號或付費服務。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 遊戲主程式：首頁、特務登記、冒險地圖、六關、證書 |
| `library.html` | 教學資料館（第六關的線索頁） |

## 部署到 GitHub Pages

1. 在 GitHub 建立一個公開儲存庫，例如 `orps-ipad-escape`。
2. 把 `index.html` 和 `library.html` 上傳到儲存庫根目錄。
3. 到 Settings › Pages，Source 選「Deploy from a branch」，分支選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約一分鐘後，網址為 `https://<帳號>.github.io/orps-ipad-escape/`。
5. 用這個正式網址產生 QR Code，印在研習講義或投影片上。

## 資料與隱私

- 老師輸入的代號、學年與進度只存在該台 iPad 的 Safari（localStorage），不會上傳。
- 不要求相機、麥克風或定位權限；語音輸入使用 iPad 鍵盤本身的聽寫功能。
- 字型從 Google Fonts 載入；若學校網路封鎖，會自動改用 iPad 內建字型，遊戲照常運作。
- 私密瀏覽模式下無法保存進度，畫面會提示。

## 種子教師解答

| 關卡 | 金鑰數字 | 通關關鍵 |
| --- | --- | --- |
| 1 電力啟動室 | 4 | 小關一：點出頂端按鈕、音量鍵、USB-C。小關二：三組操作卡配對。最後：播放音樂、按音量降低鍵聽到變小聲後打勾，鎖定再喚醒 |
| 2 手勢迷宮 | 7 | 點門（有開門聲）、長按 1.5 秒、滑動石塊、放大藏寶圖並輸入看到的密碼 7；離開 Safari 再回來（Dock、主畫面、App 切換器皆可） |
| 3 神秘控制室 | 2 | 點 Wi-Fi、藍牙（點了才亮）、旋轉鎖定、飛航；亮度拖到 45–55%；點右上角電源鈕後按「取消」；觀察題：右上角、鎖頭加圓箭頭 |
| 4 秘密文件＋AirDrop | 9 | 小關一：文件出現時截圖，貓頭鷹右下方那格的數字 9。小關二：模擬設定 一般 › AirDrop › 所有人（10 分鐘）；用 AirDrop 互傳截圖，輸入夥伴截圖上的 4 位數「文件編號」；AirDrop 被管理限制時可用替代方式過關 |
| 5 魔法文字 | 5 | 對著 iPad 上緣說「科技讓教學更有趣」（忽略標點空白，聽寫受限可打字）；點按觸控筆頭兩下開機後在畫板寫 AI |
| 6 數位校園核心 | 24597 | 口訣順序：控制、電力、創作、影像、手勢 |

選「第一次使用 iPad」的老師，每關會先顯示提示一，機密文件停留 5 秒（其他人 3 秒）。音效預設開啟，答對會有音樂與動畫，可在登記頁或右上角關閉。網頁無法偵測實體按鈕與 iPad 音量，第一關的音量任務由老師聽聲音後自行打勾。

## 時間分配

說明 4 分、第一關 6 分、第二關 8 分、第三關 8 分、第四關 10 分（含 AirDrop）、第五關 10 分、第六關 9 分、成果分享 5 分，共 60 分鐘。第四關需要兩人一組互傳，沒有夥伴時由種子教師配對。
